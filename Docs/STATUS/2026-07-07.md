# Work Completed

## 1. Ear Clipping Triangulator

The old fan fallback behaviour was removed.

Old:

```python
if not ear_found:
    return AtlasPolygonTriangulator._fan_fallback(points)
```

New:

```python
if not ear_found:
    return []
```

Result:

- Invalid polygons are skipped.
- Fake triangles are no longer generated.
- Cleaner STL output.

---

## 2. Small Building Filtering

Added minimum building area filtering.

Current value:

```python
MIN_BUILDING_AREA_M2 = 20.0
```

Purpose:

Remove tiny utility objects such as:

- transformers
- traffic islands
- road furniture
- very small sheds
- tiny cylinders
- miniature prisms

without affecting normal buildings.

Result:

Cleaner city models.

---

## 3. Minimum Printable Size

Model width filter added.

Current:

```python
MIN_MODEL_WIDTH_MM = 1.20
MIN_MODEL_DEPTH_MM = 1.20
```

Purpose:

Skip buildings that become physically too small after scaling.

# Current Conclusion

The remaining problem is **NOT** caused by building generation.

Reasons:

- More than one thousand buildings were generated successfully.
- Geometry cleaner works.
- Polygon validator works.
- Ear clipping works.
- Building meshes are consistently closed.

Therefore the remaining open edges most likely originate from the global scene assembly.

Most probable locations:

1. Base plate
2. Surface composer
3. STL mesh merging
4. STL writer

Building generation is currently considered stable.

Reason:

Only after:

- 0 Open Edges
- Fully manifold STL

will road carving continue.

This decision avoids debugging multiple systems simultaneously.
